# Code de conduite

Slayer Kit est un projet communautaire. Pour que tout le monde ait envie d'y participer :

- reste respectueux et bienveillant, dans les issues, les pull requests et les discussions ;
- critique le code, jamais la personne ;
- pas d'insultes, de harcèlement, de discrimination ni de contenu choquant ;
- ne partage jamais les données personnelles de quelqu'un d'autre.

Le mainteneur peut modifier ou supprimer les messages qui ne respectent pas ces règles et bloquer les personnes concernées. Pour signaler un comportement, contacte [@ybyns2](https://github.com/ybyns2).
