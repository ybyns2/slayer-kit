# Sécurité

Slayer Kit manipule des clés de stream et un accès GitHub : les failles sont prises au sérieux.

## Signaler une faille

N'ouvre **pas** d'issue publique. Utilise le signalement privé de GitHub : onglet **Security → Report a vulnerability** de ce repo.

Indique la version concernée, les étapes pour reproduire et l'impact. Tu recevras une réponse dès que possible, et le correctif sera publié comme mise à jour critique si nécessaire.

## Versions suivies

Seule la dernière version publiée dans les [releases](https://github.com/ybyns2/slayer-kit/releases) reçoit des correctifs de sécurité.
